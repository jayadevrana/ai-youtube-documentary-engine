# The Viral Storytelling Formula (Documentary Style)

1. Curiosity Hook (0-20s)
2. Common Belief / Illusion
3. Investigation (case studies + data + context)
4. Psychological Layer (biases, social proof, incentives)
5. Hidden Truth Reveal
6. Expansion (systems, history, examples)
7. Philosophical Ending

Retention loop every 30-40 seconds:
Insight -> Question -> Reveal -> Story -> Insight
